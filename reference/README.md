# Original material

These files preserve the research team's original code and artifacts. They are
not newly authored replacements. The runnable, organized versions live in
`experiments/`; the original versions here make substantive edits reviewable.

| Directory | Original material retained |
| --- | --- |
| `original_code/evaluation/` | Four evaluation Python files, byte-for-byte from main |
| `original_code/step3/` | Deleted historical replay code and executed verification cell, byte-for-byte |
| `original_code/tests/` | Original replay tests |
| `original_docs/` | Historical research README and vision handoff |
| `notebook_images/` | Four exact embedded JPEG/PNG outputs from the training and sanity notebooks; example images, not result plots |
| `invalid_notebook_sources/` | One historical notebook with invalid JSON, retained as plain text rather than silently repaired |

Source commits and SHA256 values are in
[`source_inventory.json`](../provenance/source_inventory.json) and
[`history_inventory.json`](../provenance/history_inventory.json). Original
recorded outputs, judged responses, tables, and tensors are in
[`results/`](../results/README.md). The historical material may contain
superseded settings, broken paths, or stronger claims than the evidence supports;
see the workflow guides before running or interpreting it.

The submitted manuscript was supplied separately and is preserved in
[`paper/submitted.pdf`](../paper/submitted.pdf), with its original figure and
transcribed tables alongside proposed replacements. Its anonymous author line
is retained; author order and a final publication citation are not invented.
